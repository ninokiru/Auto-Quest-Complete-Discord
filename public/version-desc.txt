## 🎮 Auto Quest Complete Discord

Auto-complete Discord **video, stream and game quests** from one window. Tauri 2 + Rust behind the scenes, Vue 3 on the surface, and no cloud service in between: everything runs on your machine.

## v0.0.5 L2#2 — the in-app update finally lands on the new build

Everything in L2#1 is still here. This patch fixes the in-app update: the installer did replace the application, but the helper then started the old build again, so the same update announced itself after every install.

### Fixed

- **An in-app update restarted the old build.** Release builds run from a randomly named copy of the executable in the temporary folder, so the running application is not the file that was installed. The update helper was pointed at that running copy, and the installer only ever replaces the installed file — after the install the helper started the stale copy again, the window showed the old version, and the update prompt came back. Three updates in a row left the same build on screen. The helper now restarts the executable the user actually launched, which is the file the installer just replaced.

> [!IMPORTANT]
> The fix lives in the update path itself, so a build that already has the bug cannot update into it. If you are on **L1#3** or **L2#1**, download the `-setup.exe` below once and run it; every in-app update after that installs and restarts correctly.

### Checks

- A Rust unit test covers the launcher path the helper restarts: it is only reported when the file still exists, so a deleted path falls back instead of being trusted.
- The translation check, the frontend test suite, the runtime identity checks and the full Rust test suite run on Windows for this release.

**Full Changelog**: https://github.com/ninokiru/Auto-Quest-Complete-Discord/compare/0.0.5-L2.1...0.0.5-L2.2

### How the in-app update works

1. The app compares its own version with the newest release of this repository.
2. Choosing **Update** downloads the `*-setup.exe` asset over HTTPS from GitHub.
3. The download's SHA-256 is compared with the digest GitHub publishes for that asset; a mismatch aborts before anything runs.
4. A small helper waits for this app to quit, runs the installer silently, and starts the installed executable again.

Only Windows is self-updating in this release; other platforms still get the release page link. Downloads are restricted to GitHub hosts.

### Windows SmartScreen / Defender

These binaries are **not code-signed**. The app rewrites its own process identity and reads locally stored Discord credentials, which is exactly what heuristic scanners flag, so Defender may quarantine the download and SmartScreen may block the first launch. Confirm the file came from this repository, choose **More info → Run anyway**, and add the app folder to Defender's exclusions if it keeps deleting the file.
