## 🎮 Auto Quest Complete Discord

Auto-complete Discord **video, stream and game quests** from one window. Tauri 2 + Rust behind the scenes, Vue 3 on the surface, and no cloud service in between: everything runs on your machine.

## v0.0.5 L3#6 — an Activity quest you can watch while you launch it

Sixth build of the third patch round. An audit of the Activity and CDP paths turned up five defects; these are all of them.

### Fixed

- **A started Activity quest no longer looks frozen.** Starting one waits up to five minutes for you to launch the Activity in Discord, and the card only began tracking progress *after* that wait returned — so the bar sat still and the button looked dead. The card now opens, shows that it is waiting and tracks the backend from the first second. A start that fails gives the slot back.
- **A batch says when it leaves a quest out.** Checkpoint Activity and Stream quests cannot run from a queue — one needs you to open the Activity window, the other needs a real broadcast. The batch used to drop them without a word; it now explains which quest was left out and why.
- **A missing cadence no longer means the slowest cadence.** A caller that sent no checkpoint times got the old 180 s fallback, twice the current 90–150 s default. It now runs at 120 s.

### Checks

- rustfmt, clippy, the Rust suite, the frontend suite and the translation parity check run in CI for this build.

**Full Changelog**: https://github.com/ninokiru/Auto-Quest-Complete-Discord/compare/0.0.5-L3.5...0.0.5-L3.6

### How the in-app update works

1. The app compares its own version with the newest release of this repository.
2. Choosing **Update** downloads the `*-setup.exe` asset over HTTPS from GitHub.
3. The download's SHA-256 is compared with the digest GitHub publishes for that asset; a mismatch aborts before anything runs.
4. A small helper waits for this app to quit, runs the installer silently, and starts the installed executable again.

Only Windows is self-updating in this release; other platforms still get the release page link. Downloads are restricted to GitHub hosts.

> [!IMPORTANT]
> If you are still on **L1#3** or **L2#1**, run the `-setup.exe` below once by hand. Those builds restart the old copy after an update, which L2#2 fixed; every in-app update after that install is correct.

### Windows SmartScreen / Defender

These binaries are **not code-signed**. The app rewrites its own process identity and reads locally stored Discord credentials, which is exactly what heuristic scanners flag, so Defender may quarantine the download and SmartScreen may block the first launch. Confirm the file came from this repository, choose **More info → Run anyway**, and add the app folder to Defender's exclusions if it keeps deleting the file.
