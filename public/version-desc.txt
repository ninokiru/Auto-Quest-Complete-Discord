## 🎮 Auto Quest Complete Discord

Auto-complete Discord **video, stream and game quests** from one window. Tauri 2 + Rust behind the scenes, Vue 3 on the surface, and no cloud service in between: everything runs on your machine.

## v0.0.5 L1#3 — a patch on 0.0.5

Everything that shipped in 0.0.5, L1#1 and L1#2 is still here. This patch makes the idle game session less metronome-like, makes an update you postponed reachable again, and repairs the game-idle header at the default window size.

### New

- **Fixed or random durations.** Every game-idle timer — play window, rest window, crash delay, reopen delay — now takes either a fixed value or a random one inside a range you set, so a session no longer starts and stops on the same minute every time.
- **Crash simulation.** The idle runner can close the running game at a random moment inside its play window and reopen it a short while later, the way a real disconnect does, then carry the remaining time over to the new session.
- **Post-quest connection.** A new switch in Quest behaviour keeps a simulated game connected for a while after its quest completes, so a short quest no longer drops the game the second it finishes. It applies to process-simulated quests only, and the panel says so while another mode is selected.

### Fixed

- **An update you postponed was out of reach.** Dismissing the update dialog hid that release for the rest of the session, and the only way back to the in-app installer was a link buried in Settings. The Home banner now carries an **Update now** button that reopens the installer, and the release list is refreshed on a short timer instead of being cached until restart — a release published while the window stayed open used to never appear.
- **A failed update check looked like "up to date".** When GitHub could not be reached, nothing was said anywhere in the app. Settings → About now names the error and offers a retry.
- **The game-idle header collapsed.** At the default 1200px window the start button was wrapping into the title; the title and controls now keep their own rows, and the duplicated rest-time description line is gone.

### Checks

- The Rust suite covers the random-duration range, the crash-config validation gate and the crash plan inside a play window; the frontend gained store tests for the post-quest connection timer and for the release-list cache window.
- Release runs now cache the Linux `.deb` archives, which removes the apt step that used to sit for 13 minutes while every other job finished in three.

**Full Changelog**: https://github.com/ninokiru/Auto-Quest-Complete-Discord/compare/0.0.5-L1.2...0.0.5-L1.3

### How the in-app update works

1. The app compares its own version with the newest release of this repository.
2. Choosing **Update** downloads the `*-setup.exe` asset over HTTPS from GitHub.
3. The download's SHA-256 is compared with the digest GitHub publishes for that asset; a mismatch aborts before anything runs.
4. A small helper waits for this app to quit, runs the installer silently, and starts the new build.

Only Windows is self-updating in this release; other platforms still get the release page link. Downloads are restricted to GitHub hosts.

### Windows SmartScreen / Defender

These binaries are **not code-signed**. The app rewrites its own process identity and reads locally stored Discord credentials, which is exactly what heuristic scanners flag, so Defender may quarantine the download and SmartScreen may block the first launch. Confirm the file came from this repository, choose **More info → Run anyway**, and add the app folder to Defender's exclusions if it keeps deleting the file.

They will return in a later release. If you need one of them now, build it from source (`pnpm tauri:build`).
