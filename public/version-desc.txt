## 🎮 Auto Quest Complete Discord

Auto-complete Discord **video, stream and game quests** from one window. Tauri 2 + Rust behind the scenes, Vue 3 on the surface, and no cloud service in between: everything runs on your machine.

### What's new in 0.0.3

This release is about knowing what is happening — inside the app and about the app itself.

- **Notification bell in the title bar.** One inbox for everything the app wants you to know: a new version is out, a quest finished, a quest failed, and how many new quests appeared while you were away. Unread count on the icon, per-item actions, mark-all-read and clear-all.
- **Update log tab.** Right next to the inbox, the release history of this project is read live from the GitHub Releases API — your installed version and the latest one are both labelled, and the notes render as full release text. Refresh it whenever you like.
- **Update dialog with the changelog built in.** When a newer version exists the dialog opens on its own, shows what changed, and its **Update** button now installs the release for you: it downloads the Windows installer, checks its SHA-256 against what GitHub reports, runs the installer silently, and relaunches the app. You keep your settings and your sign-in.
- **No more delete-and-reinstall.** Updating overwrites the previous install in place. If you would rather stay on this build for now, postpone — and restore the reminder from **Settings → About** at any time.
- **Stability.** Errors in the notification, version and release-log paths are caught and surfaced as inbox items instead of breaking the window; a slow version check can no longer overwrite a newer result; the bell follows a language switch immediately.
- **All 16 interface languages** carry the new strings.

### How the in-app update works

1. The app compares its own version with the newest release of this repository.
2. Choosing **Update** downloads the `*-setup.exe` asset over HTTPS from GitHub.
3. The download's SHA-256 is compared with the digest GitHub publishes for that asset; a mismatch aborts before anything runs.
4. A small helper waits for this app to quit, runs the installer silently, and starts the new build.

Only Windows is self-updating in this release; other platforms still get the release page link. Downloads are restricted to GitHub hosts.

### Windows SmartScreen / Defender

These binaries are **not code-signed**. The app rewrites its own process identity and reads locally stored Discord credentials, which is exactly what heuristic scanners flag, so Defender may quarantine the download and SmartScreen may block the first launch. Confirm the file came from this repository, choose **More info → Run anyway**, and add the app folder to Defender's exclusions if it keeps deleting the file.

They will return in a later release. If you need one of them now, build it from source (`pnpm tauri:build`).
