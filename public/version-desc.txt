## 🎮 Auto Quest Complete Discord

Auto-complete Discord **video, stream and game quests** from one window. Tauri 2 + Rust behind the scenes, Vue 3 on the surface, and no cloud service in between: everything runs on your machine.

### What it does

- **Three ways to sign in** — auto-detect the Discord profiles on your computer, connect over CDP to Discord or Vesktop, or paste a token yourself.
- **Video & stream quests** — press start once; progress keeps updating in the background while you keep using Discord.
- **Game quests without the game** — the built-in simulator pretends to be the game client, so nothing has to be downloaded or installed.
- **Up to 5 quests in parallel** — start several at once and stop any single one of them without touching the others.
- **Multi-account** — switch between Discord accounts, each with its own quest list and history.
- **Filters & diagnostics** — filter by reward type and completion state, then use the built-in connection diagnostics when something refuses to start.
- **16 interface languages** — English, Vietnamese, Chinese (Simplified and Traditional), Japanese, Korean, Russian, Spanish, German, French, Indonesian, Polish, Portuguese (Brazil and Portugal), Thai, Turkish.

### About this release

- Application name, window title, executable, installers and data directory all use the new name.
- Update checks and issue links now point at this repository.
- Settings are stored under the new identifier, so sign in once again after upgrading.

### Windows SmartScreen / Defender

These binaries are **not code-signed**. The app rewrites its own process identity and reads locally stored Discord credentials, which is exactly what heuristic scanners flag, so Defender may quarantine the download and SmartScreen may block the first launch. Confirm the file came from this repository, choose **More info → Run anyway**, and add the app folder to Defender's exclusions if it keeps deleting the file.
