# Project structure — what every file does

Companion to [README.md](README.md). README says what the app is; this file says **where everything
lives, what each file is responsible for, what the project is built with, and which file to open for
a given change**. Line counts are approximate and only there to tell you where the weight of the
project sits.

- Want to *run* the app: [docs/USAGE.md](docs/USAGE.md)
- Want to *compile* it: [docs/BUILDING.md](docs/BUILDING.md)
- Hit an error: [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md)

## The path of one click

```text
User clicks "Start Quest" (QuestCard.vue)
   └─ Home.vue handler
        └─ Pinia store src/stores/quests.ts      ← queue, 5 parallel slots, progress unit per quest
             └─ src/api/tauri.ts                 ← typed wrapper over Tauri IPC (invoke)
                  └─ src-tauri/src/lib.rs         ← #[tauri::command] registry
                       ├─ src-tauri/src/discord_api.rs      → Discord REST (quests, profile, rewards)
                       ├─ src-tauri/src/discord_gateway.rs  → Discord Gateway WebSocket
                       ├─ src-tauri/src/cdp_quest.rs        → quest execution inside the client
                       ├─ src-tauri/src/cdp_client.rs       → CDP transport, target discovery/selection
                       └─ crates/discord-cdp-launch-core    → find + launch + supervise the client
                             └─ waybridge (src-cdp-launcher) → starts Discord with --remote-debugging-port
                  └─ events back to the frontend → store state → components re-render
```

Everything is local. The only outbound traffic is Discord's own API and, for the update check,
GitHub's release API.

### Locales

`src/locales/` holds 17 JSON files — `en.json` is the baseline (622 keys) and the other 16 are
de, es, fr, id, ja, ko, pl, pt-BR, pt-PT, ru, th, tr, vi, zh, zh-TW. Key parity is enforced by
`node scripts/i18n-validate.mjs`. A key referenced by code but absent from `en.json` does **not**
fail CI — it breaks at runtime, so new strings must be added to all 16 files.

## What it is built with

| Layer | Technology |
| --- | --- |
| Shell/runtime | Tauri 2 (`tauri` + `@tauri-apps/api` 2.11), wry/WebView2/WKWebView/WebKitGTK |

| Tests | Vitest 4 (`vitest run src`) for the frontend; `cargo test --workspace` with in-module `#[cfg(test)]` tests plus the core crate's `tests/` |

## Risk areas

Two files are both the biggest and the least tolerant of casual edits: `src-tauri/src/cdp_quest.rs`
(quest execution inside someone else's renderer, with cleanup that must run on every exit path) and
`src/stores/quests.ts` (parallel slots and completion accounting). If you change either, keep the
invariants recorded in [docs/cdp-runtime-validation.md](docs/cdp-runtime-validation.md) and
[docs/USAGE.md](docs/USAGE.md#how-progress-is-counted) true.

Automating Discord quests can violate Discord's Terms of Service and may put your account at risk.
Nothing in this repository is intended to bypass payment, billing, or anti-abuse systems; scope is
quest automation only.
